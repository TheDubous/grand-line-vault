# Grand Line Vault v1.2.4 — Aktualizace GitHub Pages

**Pro již fungující v1.2.3:**

1. Udělej zálohu v aplikaci a ověř Cloud sync.
2. Nahraj všechny soubory ZIPu do kořene existujícího repozitáře `TheDubous/grand-line-vault`. Přepiš `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `VERSION.txt` a další soubory. Commit na `main`.
3. Po dokončení GitHub Pages otevři `https://thedubous.github.io/grand-line-vault/?v=1.2.4`.
4. Zkontroluj číslo verze v postranním menu a vyzkoušej skener na Shiryu `OP14-048` a Charlotte Lola `OP11-052`.

**Žádné SQL nepouštěj.** Databáze v1.2.3 zůstává beze změny.

Pokud se ve webové aplikaci na ploše iPhonu drží staré soubory, zkus ji zavřít a znovu otevřít; případně přidej nový zástupce z aktuálního Safari. Neodstraňuj lokální data bez zálohy.
